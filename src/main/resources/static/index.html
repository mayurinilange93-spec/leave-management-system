API Endpoints Reference

👥 Employee APIs

GET /api/employees - Get all employees

GET /api/employees/{id} - Get employee by ID

POST /api/employees - Create new employee

PUT /api/employees/{id} - Update employee

DELETE /api/employees/{id} - Delete employee

📋 Leave Request APIs

GET /api/leave-requests - Get all leave requests

GET /api/leave-requests/{id} - Get leave request by ID

GET /api/leave-requests/employee/{employeeId} - Get leaves for employee

POST /api/leave-requests/apply/{employeeId} - Submit leave request

PUT /api/leave-requests/{id}/approve - Approve leave

PUT /api/leave-requests/{id}/reject - Reject leave

DELETE /api/leave-requests/{id} - Delete leave request
